# 🎮 원딜러 WonDealer

> “원하는 걸 DEAL 하다”

게임 아이템·게임머니·계정을 거래하고, 실시간 경매와 채팅으로 판매자와 구매자를 연결하는 웹 서비스입니다.

**5인 팀 프로젝트를 홍유나의 개인 포트폴리오로 정리한 통합 저장소**입니다. 프론트엔드와 백엔드를 한곳에서 확인할 수 있으며, 홍유나의 개인 담당은 **백엔드 회원·인증 기능**입니다.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 개발 기간 | 2026.06.02 ~ 2026.06.19 |
| 발표 | 2026.06.22 |
| 구성 | 5명 · 백엔드 3명, 프론트엔드 2명 |
| 서비스 | 일반 판매, 실시간 경매, 거래 채팅, WonPay, 회원 관리 |
| 기술 | React 18 · Java 17 · Spring Boot · Spring Security · JPA · MySQL |

## 주요 기능

| 영역 | 구현 내용 |
| --- | --- |
| 회원·인증 | 회원가입, 이메일 인증, 로그인, 구글 OAuth, 아이디 찾기, 비밀번호 재설정 |
| 아이템 거래 | 게임·서버·카테고리 필터, 검색, 목록·상세, 판매 등록·수정 |
| 실시간 경매 | 경매 목록·상세, 입찰, 즉시 낙찰, WebSocket을 통한 현재가 갱신 |
| 거래 채팅 | 채팅방 목록, 메시지 송수신, 거래 상태 및 시스템 메시지 표시 |
| WonPay·마이페이지 | 마일리지 충전·출금 UI, 회원 정보, 판매·구매·입찰 내역 |
| 관리자 | 회원 제재, 상품 관리 화면 |
| 테마 | 다크·라이트 테마, 반응형 스타일 |

## 홍유나 담당 업무

- 회원가입: 이메일 인증, 이메일·아이디·닉네임 중복과 필수 약관 동의 검증
- 로그인: 아이디·이메일 로그인, 팀의 JWT/Security 인증 기반과 연결
- 이메일 인증: 인증 메일 발송, UUID 토큰 확인·만료 처리
- 구글 OAuth: 외부 사용자와 내부 회원·소셜 계정 연결
- 마이페이지: 내 정보·비밀번호·계좌 변경, 본인의 판매·거래·입찰 내역 조회
- 계정 복구: 아이디 찾기·마스킹, 임시 비밀번호 발급·메일 발송

JWT/Security 공통 인프라와 상품·경매·결제·채팅, 프론트 화면 전체는 팀의 담당 범위입니다. 회원 기능의 구현 파일·API·상세 설정은 [백엔드 기술 안내](backend/README.md)에 있습니다.

## 실행 방법

Java 17·MySQL·Node.js를 준비하고, [백엔드](backend/README.md)에서 DB·JWT·메일·OAuth 등의 설정을 먼저 확인합니다.

통합 저장소 루트에서 각각 별도 터미널로 실행합니다.

```powershell
# 터미널 1 · 백엔드
cd backend
.\gradlew.bat bootRun
```

```powershell
# 터미널 2 · 프론트엔드
cd frontend
npm install
npm start
```

화면은 `http://localhost:3000`, 서버는 `http://localhost:8111`입니다.

## 확인 범위

이전 포트폴리오 정리에서는 프론트 프로덕션 빌드와 공개 화면·테마 전환을 확인했습니다. 백엔드 빌드·DB·메일·결제·OAuth의 전체 연동은 미검증입니다. 이번 통합에서는 파일 보존과 문서·이미지 링크를 확인하며, 전체 서비스 실행을 새로 검증한 것은 아닙니다.

## 프로젝트 회고

회원가입·로그인부터 이메일 인증, 구글 OAuth, 계정 찾기·비밀번호 변경까지 회원 관련 기능을 담당했습니다. 이 기능들은 서로 연결되어 있어, 개별 API의 구현뿐 아니라 사용자가 가입하고 계정을 관리하는 전체 흐름을 함께 고려해야 한다는 점을 배웠습니다.

포트폴리오를 정리하면서 프론트엔드 호출과 백엔드 API 사이에 확인이 필요한 차이도 발견했습니다. 다음 프로젝트에서는 요청·응답 형식과 오류 처리 기준을 팀원들과 먼저 맞추고, 정상 동작뿐 아니라 인증 실패와 잘못된 입력까지 함께 검증하고 싶습니다.
